# 开局名称目录与更新策略

## 首版范围

客户端内置一个小型、可审阅的名称目录，只负责“局面命中与研究提示”，不参与引擎走棋。首版覆盖中炮、屏风马、顺炮、列炮、反宫马、飞相局、仙人指路、起马局和仕角炮等常见布局入口。

目录使用合法 UCI 着法生成局面键，再按棋盘布局和行棋方匹配；因此相同局面可以稳定命中，不依赖中文记谱文本。离开已收录节点后，界面继续显示本局最近一次命中的最深开局名称。

## 数据来源与许可

- 首版名称、说明和短着法由项目自行整理，不复制第三方对局统计、注释或二进制开局库，随项目以 GPL-3.0 分发。
- 若后续接入外部大规模数据，优先采用公开、可追溯的 OOBS（Open Opening Book Standard）或明确许可的数据源；合并前必须记录来源版本、许可证和生成脚本。
- MoonRiver Xiangqi OpeningBook 与 OOBS 均声明 MIT 许可，可作为后续格式和生成流程的候选参考：<https://github.com/nguyenpham/MRXqOpeningBook>、<https://github.com/nguyenpham/oobs>。

## 版本更新

`OPENING_CATALOG_VERSION` 使用 `YYYY.MM.N`。新增或修正目录时必须：

1. 更新版本号与本文件的覆盖范围。
2. 让每条着法通过现有合法走子引擎完整重放。
3. 为名称命中、最深节点和自定义 FEN 隔离补充测试。
4. 外部数据只通过可复现脚本升级，不直接手工覆盖来源不明的数据库。

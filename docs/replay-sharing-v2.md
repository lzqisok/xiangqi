# 完整变招回放链接 v2

## 数据边界

普通象棋回放链接 v2 在 URL 的 `replay` 参数中保存：

- 起始 FEN、研究名称和说明。
- 变招树根节点、当前节点、父子关系和主线选择。
- 每个节点的 UCI 着法、星标、备注、棋盘标注和节点分析。

接收端不信任节点自带局面，而是从起始 FEN 沿父子关系逐节点合法重放并重新生成 FEN。断开的节点、循环引用、错误父子关系和非法着法都会拒绝导入。旧版线性链接继续兼容。

## 容量与降级

- 最多 300 个节点。
- JSON 原始载荷最多 120KB。
- 超限时不生成残缺链接，提示用户删减分支或改用研究 JSON 导出。

这一阶段仍是客户端自包含链接，不提供服务端短码、权限、封面图片或过期时间。上述能力需要公网存储、访问身份、删除与滥用治理，不在局域网服务上提前模拟。
